## 1. 问题是什么

第一人称视角的麻将识别系统,已经能框出每张牌并认出是几万几条。**剩下的问题是:判断每张牌属于谁。**

五个区域:`my_hand`(我的手牌)/ `seat_left`(上家)/ `seat_across`(对家)/
`seat_right`(下家)/ `river`(中间的公共牌池)。

当前逐区域召回:

| 区域 | 召回 | 标注样本数 |
|---|---|---|
| my_hand | **100.0%** | 268 |
| seat_left | **100.0%** | 48 |
| river | 97.6% | 492 |
| seat_right | 96.0% | 50 |
| **seat_across** | **72.3%** ← 待解 | **65** |

整体 96.3%(交叉验证)。**对家是唯一没有随迭代改善的区域**,五轮优化里一直卡在 71~72%。
其余四个区域现在都在 96% 以上,问题已经收敛成单一目标。

### 为什么难

对家的牌与牌池在**三个维度上都重叠**:

* **位置**:对家 nx 中位 0.60,牌池 0.52,横向范围几乎完全重合(上家 0.23、下家 0.86
  在牌池范围之外,所以它们好分)
* **密度**:牌池是最密集的(弃牌堆在中间),对家次之,两者分布交叠
* **聚簇**:单链聚类会把对家的牌与牌池**串成一簇**(它们中间没有空隙)

现有的三个信号都分不开它。**需要一个新信号。**

## 3. 评测协议(务必照做,否则数字不可比)

**必须用图级 5 折交叉验证**,不能按框随机划分 —— 同一张图的牌高度相关,按框切会严重高估。

而且**阈值/参数必须在每折的训练图上重新拟合**,不能用全量数据拟合出的参数去报告交叉验证成绩。

这个项目在这上面栽过:早期报告过 92.5%,那是在同一批数据上网格搜索、再用同一批评测的
**训练集成绩**;同一个方法的诚实交叉验证成绩是 88.9%,虚高了 3.6 个点。

可直接运行的评测框架:

```python
import json, numpy as np, itertools

data = json.load(open('output/zone_annotation/zone_labels_with_class.json', encoding='utf-8'))

def cross_validate(predict_fn, grid, folds=5, seed=0):
    """predict_fn(sample, params) -> list[str],每个框一个区域标签"""
    rng = np.random.RandomState(seed)
    order = rng.permutation(len(data))
    parts = [order[i::folds] for i in range(folds)]

    def score(idxs, p):
        ok = n = 0
        for i in idxs:
            x = data[i]
            z = predict_fn(x, p)
            ok += sum(1 for a, b in zip(z, x['zones']) if a == b)
            n += len(z)
        return ok / max(n, 1)

    accs = []
    for part in parts:
        held = set(part.tolist())
        train = [i for i in range(len(data)) if i not in held]
        best = max(grid, key=lambda p: score(train, p))   # 只在训练折上选参数
        accs.append(score(part.tolist(), best))           # 在没见过的图上评测
    return float(np.mean(accs)), accs
```

自检:把下面两个基线跑一遍,数字应该对得上,否则说明数据或协议接错了。

```python
def all_river(x, p):
    return ['river'] * len(x['boxes'])

print(cross_validate(all_river, [None])[0])   # 应为 0.5298
```

报告时请给出:**整体交叉验证准确率 + 逐区域召回**(尤其 seat_across)。

参考线:

|---|---|

| **当前 v9** | **96.34%** |

（v8 在同一框架下是 96.10%。更早的 94.53% 是修正标注之前的数字,不可比。）

### 试过但没成功的特征

* **长宽比 w/h**:对家 2.08、牌池 2.45,AUC 0.32 有区分度,但加进规则后没能稳定提升。
  意外的是最扁的是上家/下家(3.8~3.9),不是对家 —— 侧面两家几乎是贴桌面平视。
* **同行牌数 / 该行跨度**:对家的行跨度最小(0.18,牌池 0.29),v6 用它把对家提到 85.5%,
  但牌池掉 2 个点,总分反而降 0.33。**如果你的目标函数更看重对家,v6 是可取的**。

### 成功的:定缺(v9,已并入现行实现)

四川麻将有**定缺**——宣告缺一门花色,把那张牌单独摆在自己面前。它是**单独一张**,
所以过不了"成簇"判据(`left_max_nn`),此前**每一张定缺牌都被判进了牌池**。

标志它的不是密度而是**间距**:孤立的边家牌离最近一张池牌中位 **4.1 倍自身宽**,
而池牌自己只有 **0.7**。这个特征不需要标注就能算——牌池按定义就是"密集的那堆":

```
dense = {i : 最近邻距离 <= 0.55 倍自身宽}      # 密集区 = 牌池主体
gap[i] = 到 dense 中最近一个的距离 / 自身宽度
判某家 = 位置符合 且 (成簇 或 gap >= 2.0)
```

`seat_left` 93.8% → **100%**,牌池 −0.2,总分 96.10% → **96.34%**。5 折里有 4 折
独立选中了 gap=2.0。**对家纹丝不动**——定缺和对家的问题是两回事。

退化保护:若画面里没有任何密集牌,则没有"牌池"可比,gap 记为 0(不作为判据)。
否则在没有牌堆的画面里,这条规则会激进地乱认边家——那正是 v1~v3 只有 39.7% 的原因。
### 更正:副露(碰杠)这条线索之前被我判错了

本文早先写着"20 张图里只找到 5 组同类连排,样本不足以验证"。**这个数字是错的**,
当时的搜索条件太严。重新统计(同类别 + 中心距 < 1.6 倍牌宽,单链聚合):

* 实际有 **74 组**同类连排,覆盖 226 个框。
* **其中 72 组的区域标签完全一致**;仅有的 2 组不一致(z03 的 t9、z14 的 t5)
  经核对**都是上面列出的标注错误**。也就是说,"同类连排必属同一家"在这份数据上
  **零反例**。这是比几何单链聚类可靠得多的分组约束 —— 几何聚类恰恰会把对家串进牌池。
* 组的区域分布:自家 24 / 对家 17 / 牌池 11 / 下家 11 / 上家 11。
  所以"连排 ⇒ 是某家的副露"**不成立**(牌池也会出现 3 张相同的弃牌),
  这个信号的价值在于**分组**,不在于直接定区域。

**最关键的一点:seat_across 的 18 个错误里,16 个(89%)就在这些连排组里。**

具体是 6 组碰牌:z01 的 t9、z03 的 w1、z04 的 w9、z09 的 b3、z10 的 w1 与 b6。
每组 3 张全部被判成了 river。

注意这不能靠"组内多数投票"解决 —— 一组里三张全错,投票只会把错误固化。
可行的方向是**把一组当成一个整体来判**:碰牌是紧密对齐、间距规整的同类三连,
与弃牌堆的散乱纹理不同,聚合之后的行对齐度/间距方差可能才是可分的特征。
这条没人试过,而它对应着对家 89% 的错误。

### v6 的取舍(值得重新评估)

v6 让对家 71.0% → 85.5%,代价是牌池 97.2% → 95.1%,总分 -0.33。
牌池有 472 个样本、对家只有 62 个,所以总分被牌池主导。

**但下游是打牌模型,它要的是"每家分别打了什么"** —— 牌池本来就是归属不明的公共堆,
判错影响小;对家判错意味着那家的牌河记漏。**按业务价值,v6 可能比 v8 更好。**
这个取舍还没定,可以由你重新评估。

## 5. 还没试过的方向

0. **把碰牌组当整体判**(最有价值,见第 4 节的更正段)。对家 89% 的错误集中在这里。
1. **牌面朝向**。对家的牌是倒着朝向我们的,牌面文字方向相反。检测器目前只输出轴对齐框,
   不含朝向;要用这个信号得改检测器(输出旋转框)或对 crop 做朝向判别。
2. **时序**。对家出牌时,新牌从对面方向进入画面;结合麻将逆时针轮转顺序可以反推归属。
   不需要改模型,但需要跨帧信息(现在的区域判定是单帧的)。
   注:上层流水线已经按 track 生命期对区域做多数投票,把单帧 3~11% 的抖动降到 2~8%。
3. **桌面几何**。估计桌子的四个方位再按扇区划分。早期试过一版(v2),因为桌心估计不准而失败,
   但那时没有标注数据可验证,现在有了。
4. **扩标注**。三家的样本只有 163 个(占 18%),而对家恰恰最难。用现成工具再标 20~30 张
   (约 15 分钟)可以让三家样本翻倍。注意:**选图时要避开洗牌/牌局结束的画面**,
   那时牌散在桌上,区域概念不存在。

## 6. 约束

* **不要塞进模型**。区域判定必须保持为独立的后处理代码:牌面识别模型是稳定的,桌面几何
  随人/桌/机位而变,把两者绑在一起会让每次机位变化都要重训。而且终点是 AI 眼镜(全新域),
  几何规则重新标 20 张图半小时就能适配,学出来的区域头要重标数千框。
* **可以用小模型**,只要它独立于检测器、输入是几何特征(位置/尺寸/邻居关系)。923 个样本
  现成可用。但注意决策树实测 90.8% 反而不如手写规则 —— 20 张图太少,
  人工编码结构比让模型自己学更省数据。而且这一版最大的两个进步(定缺间距、碰牌分组)
  **都来自麻将规则而不是数据**,这是 20 张图的规模下最划算的信息来源。
* **保持可解释**。当前是 5 条 if-else,改一个数就能重新验证,不用重训。
